# 鹰眼APP之界面美化

美化前端设计后的版本——可在Android Studio的虚拟机上运行~

## 新增功能
- **搜索功能**：按照内容模糊搜索
- **类别信息统计**：统计历史记录中的诈骗与正常短信比例
- **诈骗来源分析**：统计诈骗短信中高频出现的发信人Top10
